# 全站内容后台管理改造计划

## 背景

当前网站大量内容硬编码在 `src/data/mockData.ts` 中，包括首页 Hero、核心优势、公司简介、联系方式、发展历程等。用户要求**所有网页显示的内容都能通过管理后台进行增删改查**，包括演示图片。

## 现状分析

### 已通过 API 管理的内容
- 产品（Products）✅ 已有 CRUD
- 新闻（News）✅ 已有 CRUD
- 专利（Patents）✅ 已有 CRUD
- 表单提交（Submissions）✅ 已有查看/删除

### 仍为硬编码的内容（需改造）
| 内容 | 所在文件 | 字段 |
|------|---------|------|
| Hero 区域 | Home.tsx / Hero.tsx | title, subtitle, description, ctaText, 背景图 |
| 核心优势(4个) | Home.tsx / FeatureCard.tsx | icon, title, description |
| 公司简介 | About.tsx | introduction, applications, philosophy |
| 企业使命/愿景/价值观 | About.tsx | mission, vision, values[] |
| 发展历程 | About.tsx / Timeline.tsx | year, title, description[] |
| 联系信息 | Contact.tsx / Footer.tsx | address, phone, email, workingHours |
| 页脚链接 | Footer.tsx | 三组链接列表 |
| 导航菜单 | Header.tsx | 导航项列表 |

## 实施方案

### 一、后端改造 (`server/index.js`)

#### 1. 新增 `siteSettings.json` 数据存储
```json
{
  "hero": { "title": "...", "subtitle": "...", "description": "...", "ctaText": "...", "bgImage": "..." },
  "features": [{ "icon": "Lightbulb", "title": "...", "description": "..." }],
  "companyInfo": { "introduction": "...", "applications": "...", "philosophy": "...", "mission": "...", "vision": "...", "values": ["创新","诚信","责任","共赢"] },
  "contactInfo": { "address": "...", "phone": "...", "email": "...", "workingHours": "..." },
  "timeline": [{ "year": "2024", "title": "...", "description": "..." }],
  "navLinks": [{ "name": "首页", "path": "/" }],
  "footerLinks": [{ "title": "产品服务", "links": [...] }]
}
```

#### 2. 新增 API 端点
- `GET /api/settings` — 获取全部站点设置
- `PUT /api/settings` — 更新全部站点设置（JSON body）
- `POST /api/upload` — 通用图片上传（multipart/form-data），返回 `{ path: '/uploads/xxx.jpg' }`

#### 3. 启动时初始化
- 如果 `siteSettings.json` 不存在，从 mockData 的默认值初始化

### 二、前端 API 配置 (`src/config/api.ts`)

新增：
```typescript
export const API_URLS = {
  // ...existing
  settings: `${API_BASE_URL}/api/settings`,
  upload: `${API_BASE_URL}/api/upload`,
};
```

### 三、管理后台改造 (`src/pages/Admin.tsx`)

#### 1. 新增"网站设置"Tab
在现有 tabs 数组中添加：
```typescript
{ id: 'settings' as TabType, label: '网站设置', icon: Settings }
```

#### 2. 设置页面使用子 Tab 分区
- **首页设置**：Hero 区域表单 + 核心优势列表（可增删改）
- **关于我们**：公司简介、使命、愿景、价值观 + 发展历程列表（可增删改）
- **联系信息**：地址、电话、邮箱、工作时间
- **导航与页脚**：导航菜单项 + 页脚链接组

#### 3. 通用图片上传组件
- 支持文件上传（调用 `/api/upload`）
- 支持输入外部 URL
- 上传后显示预览

#### 4. 数组类型编辑器
对于 features、timeline、values 等数组字段：
- 显示现有条目列表
- 每个条目有编辑/删除按钮
- "添加"按钮新增空条目

### 四、前端页面改造

#### 改造策略
所有页面改为**优先从 API 获取数据，API 失败时使用 mockData 作为兜底**。

#### 需修改的文件

1. **`src/pages/Home.tsx`**
   - Hero 数据从 API 获取（替换 `heroData` 硬编码）
   - Features 从 API 获取（替换 `features` 硬编码）
   - 移除 mockData 直接引用

2. **`src/components/Hero.tsx`**
   - 接收 props 而非从 mockData 导入
   - 背景图 URL 从 props 获取

3. **`src/components/FeatureCard.tsx`**
   - 无需修改（已接收 props）

4. **`src/pages/About.tsx`**
   - companyInfo 从 API 获取
   - Timeline 数据从 API 获取

5. **`src/components/Timeline.tsx`**
   - 接收 props 而非从 mockData 导入

6. **`src/pages/Contact.tsx`**
   - contactInfo 从 API 获取

7. **`src/components/Header.tsx`**
   - navLinks 从 API 获取

8. **`src/components/Footer.tsx`**
   - contactInfo 从 API 获取
   - footerLinks 从 API 获取

### 五、数据初始化

首次部署时，后端自动将 mockData 中的默认值写入 `siteSettings.json`，确保网站有初始内容可展示。

## 验证方式

1. 启动前后端服务
2. 访问管理后台 → 网站设置 → 修改 Hero 标题 → 保存
3. 刷新首页 → 确认标题已更新
4. 修改核心优势 → 保存 → 刷新首页确认
5. 修改公司简介 → 保存 → 刷新关于我们页面确认
6. 修改联系信息 → 保存 → 刷新联系我们和页脚确认
7. 上传新图片 → 确认图片正确显示
8. 停止后端 → 确认前端使用 mockData 兜底显示
